# Proyecto-Inicial (mi-app)

Aplicación web y móvil: Next.js + Supabase, publicada en Vercel y empaquetada para móvil con Capacitor.

## Desarrollo

```bash
npm install
npm run dev      # http://localhost:3000
npm run check    # lint + tipos + tests
```
